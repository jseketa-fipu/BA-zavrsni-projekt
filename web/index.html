Artifact registry — firmware sign-off on chain
Local demo, no wallet

Drop a build here to check whether it was cleared for release.

The file never leaves this machine. Only its SHA-256 digest is looked up, and only the digest is ever written to the chain.

Reviewers sign a build off chain, so approving costs them nothing and needs no funded account. The signatures collect here and go on chain together in one transaction, paid for by whoever submits them. The digest is a plain SHA-256, reproducible offline with sha256sum firmware.bin.
